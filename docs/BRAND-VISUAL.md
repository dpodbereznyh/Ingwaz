## Mark

Упрощённый ромб **Ingwaz ᛜ** (обводка + внутренний diamond).  
Не ᛝ, не Othala ᛟ, не рунический алфавит в body, не ДНК.

## Палитра (имена)

| Токен | Роль |
|-------|------|
| `--ig-soil` | текст |
| `--ig-field` / `--ig-chaff` | фоны |
| `--ig-leaf` | CTA / ссылки |
| `--ig-grain` | редкий акцент |
| `--ig-mist` | приглушённый текст |

Hex и полный блок `:root` — в **PORTFOLIO-BRAND-VISUAL.md**.

Избегаем: dark-cyber, фиолетовый AI-градиент, cream+terracotta+serif-штамп, неон-руны.

## Тип

**IBM Plex Sans** (display + UI). Не Fraunces, не Montserrat+Open Sans как бренд-стек.

## Копирайт

Публичные H1 / SEO — прямые, под запрос. Руны / «семя–урожай» — только визуал и внутренние доки.

## Layout

- Контейнер **1400px** (`--ig-container`); BP **1280 / 960 / 760 / 540**.
- SPA mount: **`<main id="root">`**, не `div`.
- Hero/оффер: контент в контейнере, full-bleed только фон (atmosphere).
- FAQ: аккордеон `details`/`summary`, hairline, leaf-chevron (не плоский длинный `dl`).
- Подробности — в **PORTFOLIO-BRAND-VISUAL.md** §6–7.

## Motion

Раскрытие / дыхание ромба, мягкий focus на CTA. Без sparkle и glow-стека.
